# Pood สำหรับ Windows

พูดแทนพิมพ์ได้ทุกโปรแกรม: คลิกช่องที่จะพิมพ์ กด `Ctrl+Shift+Space` แล้วพูด กดอีกครั้งเมื่อพูดจบ ข้อความภาษาไทย (ปนอังกฤษได้) ที่เรียบเรียงแล้วจะไปอยู่ในช่องนั้นเอง

repo นี้ใช้แจกไฟล์โปรแกรมเท่านั้น ไม่มีซอร์สโค้ด

## ดาวน์โหลด

**[ดาวน์โหลด Pood.exe เวอร์ชันล่าสุด](https://github.com/krit9354/pood-releases/releases/latest/download/Pood.exe)** · Windows 10 หรือ 11 (64 บิต)

วิธีติดตั้งและแก้ปัญหา: https://pood-production.up.railway.app/download

## ข้อควรรู้

- ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info** แล้วกด **Run anyway** เพราะโปรแกรมยังไม่มีใบรับรองผู้พัฒนา
- ตรวจไฟล์ได้จากค่า SHA-256 ที่แนบไว้ในแต่ละ release
